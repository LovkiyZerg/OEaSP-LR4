# Лабораторная работа №4: Взаимодействие потоков (взаимное исключение и синхронизация)

## Сведения о работе
*   **Вариант:** 1 (Модель «Обедающие философы»)
*   **Алгоритм:** Упорядоченный захват ресурсов (Ordered Capture)
*   **Механизм синхронизации:** Critical Section
*   **Студенческий ID (STUDENT_ID):** 8

## Индивидуальные параметры
В соответствии с заданием, используются следующие расчетные параметры:
*   `SEED` = 1000 + (STUDENT_ID * 97) = **1776**
*   `OPERATIONS` (базовое количество циклов) = 100 + (STUDENT_ID * 5) = **140**

## Краткое описание программы
Программа представляет собой консольное многопоточное приложение на языке C++, моделирующее классическую задачу синхронизации «Обедающие философы». 

За круглым столом сидят \(N\) философов, между которыми находится \(N\) вилок. Для приема пищи философу необходимо захватить две соседние вилки. Каждый философ циклически выполняет действия: размышляет (`THINKING`), ожидает вилки (`WAITING`), принимает пищу (`EATING`).

Для предотвращения взаимной блокировки (Deadlock) реализован алгоритм **упорядоченного захвата**: философ всегда сначала пытается взять вилку с меньшим индексом, а затем — с большим. Для защиты общих ресурсов (вилок) используются объекты `CRITICAL_SECTION`.

## Требования к среде выполнения
*   **ОС:** Windows 10 / 11 (x64).
*   **Среда разработки:** Visual Studio 2022 (или новее).
*   **Язык:** C++ (стандарт C++17 или выше).
*   **Библиотеки:** Windows API (Win32).

## Инструкции по сборке
1. Откройте файл решения (`.sln`) в Visual Studio.
2. Убедитесь, что выбрана конфигурация **Release** и платформа **x64**.
3. В меню выберите **Сборка -> Собрать решение** (Build -> Build Solution).
4. Исполняемый файл будет находиться в директории `x64/Release/`.
